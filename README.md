# Food Delivery App UI Kit

Complete production ready high fidelity UI kit and fully interactive prototype for a modern food delivery mobile application.

## 🚀 Live Demo
[Open full interactive Figma prototype](https://www.figma.com/proto/jLROLeAh7p8pxzt74HXdvn/delivery?node-id=213-6&t=0qqAVxZ9V8pL4NCl-1)

This is not just a set of static screens. This is a fully clickable end to end prototype with all transitions, microinteractions and the complete user journey implemented.

## ✨ Features
- Dark mode first design
- Clean modern minimal visual style
- Complete end to end user flow
- Polished microinteractions and animations
- Mobile first 360px base size
- Fully organised, layered Figma file
- All components and colours defined as Figma styles
- Ready to use for development or modification

## 📱 All Screens Included
* Splash screen
* Onboarding
* Location selector
* Home feed with categories
* Restaurants listing
* Restaurant detail page
* Product variant selector
* Shopping cart
* Checkout
* Live order tracking
* Order history
* User profile

## 🎨 Design Specs
- 8px base grid
- Screen size: 360px
- 4px rounded geometry system
- Neutral accessible dark mode palette
